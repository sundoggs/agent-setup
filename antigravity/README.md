# Sundogs for Google Antigravity (CLI `agy`, app and IDE)

Generated by scripts/build-distribution.mjs from registry/src/other-agents.ts. Do not edit by hand. Checked against Antigravity CLI 1.5.0 (antigravity.google/docs, 2026-11-04).

## 1. Connect the registry (MCP)

Create an API key on your account page (https://sundo.gs/account/agents, "download" permission) and export it as `SITE_APPS_KEY` before you start the agent. Never paste it into the chat.

Put `mcp_config.json` from this folder in `~/.gemini/config/mcp_config.json` (shared by the CLI, the app and the IDE), or run:

```
agy mcp add --header "Authorization: Bearer $SITE_APPS_KEY" sundogs https://sundo.gs/mcp
```

API key. Antigravity's browser sign-in needs dynamic client registration or a client id registered for `https://antigravity.google/oauth-callback`; the store has neither.

Antigravity doesn't expand `${...}` in headers, so the key itself is written into that file (the command above lets your shell fill it in). Keep it in the file in your home folder, never in a project's `.agents/mcp_config.json`.

## 2. Add the skills

Copy the folders from `../skills/` into the project's `.agents/skills/`. Where Google Antigravity (CLI `agy`, app and IDE) reads skills and instructions: `.agents/skills/` (also `~/.gemini/config/skills/`); rules from `AGENTS.md`, `GEMINI.md` and `.agents/rules/`. The `AGENTS.md` section in `../codex/AGENTS.md` works for any agent that reads `AGENTS.md`.
