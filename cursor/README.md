# Sundogs for Cursor

Generated by scripts/build-distribution.mjs. Do not edit by hand.

1. **Connect the registry.** Open the link in `install-link.txt` (Cursor asks to install the server), or copy `mcp.json` to `.cursor/mcp.json` in the project (or `~/.cursor/mcp.json` for all projects). Cursor starts the browser sign-in the first time a tool needs it. The `auth` block is needed: Cursor signs in to the store as its fixed client `cursor`, because Cursor has no client metadata document and the store doesn't take dynamic registration. If the browser sign-in fails, use an API key (below).
2. **Skills.** Cursor loads Agent Skills from `.agents/skills/` (project) and `~/.agents/skills/` (all projects). Copy the folders from `../skills/` there.
3. **Rule (optional).** Copy `rules/sundogs.mdc` to `.cursor/rules/sundogs.mdc`. It points the agent at the server and the skill.

Headless / CI: create an API key (account page, "download" permission), export it as `SITE_APPS_KEY` and use
`"headers": { "Authorization": "Bearer ${env:SITE_APPS_KEY}" }` in `mcp.json` instead of the sign-in.
