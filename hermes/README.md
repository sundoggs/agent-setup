# Sundogs for Hermes Agent (Nous Research)

Generated by scripts/build-distribution.mjs from registry/src/other-agents.ts. Do not edit by hand. Checked against Hermes Agent 0.19.0 (PyPI `hermes-agent[mcp]`, hermes-agent.nousresearch.com docs, 2026-11-04).

## 1. Connect the registry (MCP)

Create an API key on your account page (https://sundo.gs/account/agents, "download" permission) and export it as `SITE_APPS_KEY` before you start the agent. Never paste it into the chat.

Put `config.yaml` from this folder in `~/.hermes/config.yaml` (put the key in `~/.hermes/.env`).

API key. Hermes 0.19 signs in with dynamic client registration, which the store doesn't offer. Its docs and main branch already identify Hermes with a client metadata document; once that ships, `auth: oauth` and `hermes mcp login` should work (not tested).

A plain `pip install hermes-agent` has no MCP client: install `hermes-agent[mcp]` (or use the official installer). Check with `hermes mcp test sundogs`.

## 2. Add the skills

Copy the folders from `../skills/` into the project's `.agents/skills/`. Where Hermes Agent (Nous Research) reads skills and instructions: `.agents/skills/` in the repo after `hermes skills trust` (also `~/.hermes/skills/`; add `~/.agents/skills` under `skills.external_dirs`); it reads `AGENTS.md`. The `AGENTS.md` section in `../codex/AGENTS.md` works for any agent that reads `AGENTS.md`.
