# Sundogs for opencode

Generated by scripts/build-distribution.mjs from registry/src/other-agents.ts. Do not edit by hand. Checked against opencode 1.19.5 (opencode.ai/docs, 2026-11-04).

## 1. Connect the registry (MCP)

Create an API key on your account page (https://sundo.gs/account/agents, "download" permission) and export it as `SITE_APPS_KEY` before you start the agent. Never paste it into the chat.

Put `opencode.json` from this folder in `opencode.json` in the project, or `~/.config/opencode/opencode.json` for all projects.

API key. opencode's browser sign-in registers itself with dynamic client registration, which the store doesn't offer, so `"oauth": false` stops it trying.

Kilo Code's CLI (`kilo`) is built on opencode: the same `mcp` entry works in `~/.config/kilo/kilo.jsonc`.

## 2. Add the skills

Copy the folders from `../skills/` into the project's `.agents/skills/`. Where opencode reads skills and instructions: `.agents/skills/` (also `.opencode/skills/` and `.claude/skills/`, and the same under `~/`); it reads `AGENTS.md`. The `AGENTS.md` section in `../codex/AGENTS.md` works for any agent that reads `AGENTS.md`.
