# Sundogs for GitHub Copilot (CLI and VS Code)

Generated by scripts/build-distribution.mjs from registry/src/other-agents.ts. Do not edit by hand. Checked against Copilot CLI 1.0.105 (docs.github.com, code.visualstudio.com, 2026-11-04).

## 1. Connect the registry (MCP)

Create an API key on your account page (https://sundo.gs/account/agents, "download" permission) and export it as `SITE_APPS_KEY` before you start the agent. Never paste it into the chat.

Put `mcp-config.json` from this folder in `~/.copilot/mcp-config.json` (Copilot CLI and VS Code), or `.mcp.json` in the repo, or run:

```
copilot mcp add --transport http --header 'Authorization: Bearer ${SITE_APPS_KEY}' sundogs https://sundo.gs/mcp
```

API key. VS Code also publishes a client metadata document, so its browser sign-in may work without a key (not tested); Copilot CLI's uses dynamic client registration.

## 2. Add the skills

Copy the folders from `../skills/` into the project's `.agents/skills/`. Where GitHub Copilot (CLI and VS Code) reads skills and instructions: `.agents/skills/` (also `.github/skills/`, `.claude/skills/`, `~/.copilot/skills/`); it reads `AGENTS.md` and `.github/copilot-instructions.md`. The `AGENTS.md` section in `../codex/AGENTS.md` works for any agent that reads `AGENTS.md`.
