# Sundogs for Gemini CLI

Generated by scripts/build-distribution.mjs from registry/src/other-agents.ts. Do not edit by hand. Checked against Gemini CLI 0.66.0 (google-gemini/gemini-cli docs, 2026-11-04).

## 1. Connect the registry (MCP)

Create an API key on your account page (https://sundo.gs/account/agents, "download" permission) and export it as `SITE_APPS_KEY` before you start the agent. Never paste it into the chat.

Put `settings.json` from this folder in `~/.gemini/settings.json` (or `.gemini/settings.json` in the project).

API key. Gemini CLI's browser sign-in uses dynamic client registration, which the store doesn't offer.

Use `httpUrl` (Streamable HTTP); `url` means the old SSE transport. MCP servers stay off until the folder is trusted. Check with `gemini mcp list`.

## 2. Add the skills

Copy the folders from `../skills/` into the project's `.agents/skills/`. Where Gemini CLI reads skills and instructions: `.agents/skills/` (also `.gemini/skills/`, `~/.agents/skills/`); context from `GEMINI.md` (set `context.fileName` to read `AGENTS.md`). The `AGENTS.md` section in `../codex/AGENTS.md` works for any agent that reads `AGENTS.md`.
