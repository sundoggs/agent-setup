# Sundogs (Claude Code plugin)

Generated by scripts/build-distribution.mjs. Do not edit by hand.

Adds the Sundogs registry's MCP server (`sundogs`, https://sundo.gs/mcp, browser sign-in) and these skills:

- `/sundogs:site-apps-getting-started`: first-time setup, one lesson at a time (Cloudflare account, a site, the domain, the free apps, a first win). Keeps progress in `.site-apps/onboarding.md` so a new session resumes.
- `/sundogs:sundogs [what the site needs]`: find, claim, download and install apps. Also loads by itself when you ask for a feature for your site.
- `/sundogs:site-apps-update`: update the apps in this repo.
- `playbook-*`: free how-tos the agent can follow to build something itself.

Install: `/plugin marketplace add sundoggs/agent-setup`, then `/plugin install sundogs@sundogs`.

Headless or CI (no browser): create an API key with the "download" permission on your account page, then add a key-based server instead of signing in:
`claude mcp add --transport http -s user sundogs https://sundo.gs/mcp --header "Authorization: Bearer $SITE_APPS_KEY"`
Use the name `sundogs` (it replaces the browser sign-in entry: run `claude mcp remove sundogs -s user` first if you added that one); remove the header to go back to browser sign-in. Claude Code never falls back from a rejected header to the browser sign-in, so keep one entry, not both.
Use a variable name that is not an Anthropic or cloud credential name: Claude Code reads those as empty in remote server headers.
