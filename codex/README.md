# Sundogs for Codex

Generated by scripts/build-distribution.mjs. Do not edit by hand.

## 1. Connect the registry (MCP)

```
codex mcp add sundogs --url https://sundo.gs/mcp
codex mcp login sundogs --scopes catalog:read,download,checkout:create
```

or paste `config.toml` from this folder into `~/.codex/config.toml` (all projects) or `.codex/config.toml` (one trusted project) and run `codex mcp login sundogs`. The login opens the browser. The IDE extension has the same under MCP servers, then Authenticate.

## 2. Add the skills (optional but recommended)

Codex reads skills from `.agents/skills` in the repo (or `$HOME/.agents/skills` for all projects). Copy the folders from `../skills/`:

```
git clone --depth 1 https://github.com/sundoggs/agent-setup "$(mktemp -d)/kit" && echo "then copy kit/skills/* into .agents/skills/ (repo) or ~/.agents/skills/ (all projects)"
```

or ask Codex: "install the skills from https://github.com/sundoggs/agent-setup (the skills folder) with $skill-installer". Restart Codex if they do not show up; `/skills` or `$` lists them.

## 3. Optional: AGENTS.md

Append `AGENTS.md` from this folder to the project's `AGENTS.md` so every session knows where to look.

## Headless / CI

Create an API key (account page, "download" permission), export it as `SITE_APPS_KEY` and uncomment `bearer_token_env_var` in `config.toml`.
